# ガールズ競輪AI・極 KIWAMI

iPhone/Safari対応の静的Webアプリです。GitHub Pagesで公開するためのファイル一式です。

## 公開手順
1. GitHubリポジトリの Add file → Upload files を選ぶ。
2. このフォルダ内の4ファイル（index.html, manifest.json, sw.js, icon.svg）をアップロードして Commit changes。
3. Settings → Pages → Deploy from a branch → main / root → Save。
4. 数分後、https://kiyo5179.github.io/kiwami-girls-keirin/ を開く。

## 注意
選手情報の自動取得・公式データAPI・実オッズ連携は未接続。簡易確率モデルの参考値で、的中や利益を保証しません。入力・履歴はブラウザ内保存です。
